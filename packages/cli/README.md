# Godot MCP cli

Command-line interface (`init`, `doctor`, `config`) for initializing and diagnosing Godot MCP integration in Godot 4.x projects.

Part of the [Godot MCP](https://github.com/SrDarkoll/godot-mcp) monorepo. Node.js 22+ is required. Prepared as a hardened Developer Preview release candidate (v0.2.0).
