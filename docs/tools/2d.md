# 2D power tools

Godot MCP provides focused helpers for common Godot 4.x 2D scene authoring. These tools are intentionally higher-level than `node.*`, `object.*`, and `resource.*`; use the generic tools for advanced properties that are not covered here.

## Node2D transforms

- `node2d.inspect_transform` returns local position/rotation/scale/skew plus global position/rotation/scale.
- `node2d.set_transform` atomically changes one or more local transform fields and records one editor Undo/Redo action.

Example arguments:

```json
{
  "node_path": "/Main/Player",
  "position": {"x": 120, "y": 80},
  "rotation_degrees": 15,
  "scale": {"x": 1.25, "y": 1.25}
}
```

## Sprite2D

- `sprite2d.inspect`
- `sprite2d.set_texture`
- `sprite2d.configure`

`set_texture` accepts a project `res://` Texture2D path or `null`/`""` to clear it. The texture path participates in the normal project-filesystem security fingerprint.

`configure` supports centering, offset, horizontal/vertical flip, `hframes`, `vframes`, `frame` or `frame_coords`, region enablement/rectangle, and region filter clipping. The requested frame must fit the prospective frame grid; `frame` and `frame_coords` cannot be supplied together.

## Camera2D

- `camera2d.inspect`
- `camera2d.configure`

The configure tool authors persistent scene settings: enabled state, zoom, offset, rotation handling, four limits, limit smoothing, position/rotation smoothing and four drag margins. It deliberately does not call `make_current()` because current-camera ownership is runtime/viewport state.

Zoom must be positive. Drag margins are constrained to `0..1`. Prospective limits must satisfy left <= right and top <= bottom.

## CollisionShape2D

- `collision2d.inspect`
- `collision2d.set_shape`

The specialized authoring tool creates embedded resources for:

```json
{"kind":"rectangle","size":{"x":64,"y":24}}
{"kind":"circle","radius":12}
{"kind":"capsule","radius":10,"height":40}
```

Pass `shape: null` to clear the node. Capsule height must be at least twice its radius. Undo restores the exact previous Shape2D resource.

Unknown Shape2D subclasses remain inspectable as `other`; use generic resource/object tools for unsupported custom shape authoring.

## Parallax2D

- `parallax2d.inspect`
- `parallax2d.configure`

Supported fields are `repeat_size`, `repeat_times`, `scroll_scale`, `autoscroll`, `scroll_offset`, `screen_offset`, `follow_viewport`, `limit_begin`, and `limit_end`. A single call is one Undo/Redo action.

This helper targets modern `Parallax2D`, not legacy `ParallaxBackground`/`ParallaxLayer` authoring.

## Scope boundaries

This phase does not add AnimatedSprite2D/SpriteFrames, physics-body movement, collision layers/masks, or Navigation2D. Dedicated 3D/material helpers are documented separately in `docs/tools/3d-materials.md`; the generic MCP surface remains available for advanced properties outside both guides.
