# Godot MCP 0.6.5

Removes redundant approvals from bounded, routine project work and fixes stale GDScript inspection while preserving controls for destructive operations.

- Common project settings and local headless validation/import/run/tests use their existing session permissions without another approval prompt.
- Closing a named scene saves first. Failed saves leave it open, unnamed scenes require saving, and explicit `discard_changes: true` still requires approval. A new server refuses unsafe default closing with an older addon.
- GDScript inspection by path compiles fresh disk source in an independent resource without reloading live instances. Invalid/deleted source no longer returns cached valid metadata.
- External access, existing-file overwrites, reflective calls, snapshot restoration and unproven undo/redo remain protected.
- The fully bundled public runtime is retained. Protocol remains 1 and the catalog remains 194 tools.

## Update

```powershell
npm install -g @srdarkx/godot-mcp@0.6.5
```

Preview and upgrade each intended project separately:

```powershell
npx --yes @srdarkx/godot-mcp@0.6.5 upgrade . --dry-run
npx --yes @srdarkx/godot-mcp@0.6.5 upgrade .
```

Review session restart and launcher changes before confirming. Backups and per-project configuration are retained. Reload an already-open Godot addon and reconnect the MCP client after upgrading that project; updating the global package alone does not change pinned launchers or loaded addon code.

Node.js 22 or newer is required. Native verification targets Windows and Godot 4.6.3; other engines/languages do not gain a new blanket compatibility guarantee.
