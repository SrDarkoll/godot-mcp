# Godot MCP 0.6.2

`upgrade` previously rejected valid Codex configurations that launched the server through a retry script or directly from the source workspace. The updater now recognizes those layouts, shows the proposed npm launcher and asks once before replacing custom behavior or stopping the authenticated project session. It keeps the script file and backs up the original configuration without changing other MCP entries, environment tables or server options.

From your Godot project:

```powershell
npx --yes @srdarkx/godot-mcp@0.6.2 upgrade . --dry-run
npx --yes @srdarkx/godot-mcp@0.6.2 upgrade .
```

The preview shows the version transition, configuration change, session impact and backup directory without writing files, starting Godot or stopping a session. For automation, `--replace-launcher` approves replacing a source/custom launcher and `--yes` separately approves session shutdown. Neither JSON mode nor `--yes` silently discards custom script behavior.

`init` detects an existing project-local Codex entry and routes it into the same preview and confirmation flow. Interactive questions also work when terminal output is redirected. Cancelling preserves the installation and session. A configuration edited during confirmation cancels the update before shutdown; verification failure restores the custom configuration. Failures after an approved shutdown explain that the session remains stopped and must be reconnected.

Validation includes 411 unit tests, 28 Godot integration tests, compilation of 42 addon scripts and the generated logger, and an external consumer installed from the exact release tarball. The consumer gate exercises preview, refusal without launcher consent, approved migration, exact backups and preservation of the script. See the [upgrade guide](../upgrading.md) and [verification report](../testing/2026-10-09-upgrade-launcher-verification.md).

Project maintenance remains Windows-specific and migrates project-local Codex configuration. After updating, rescan or reopen Godot and reconnect the MCP client.
