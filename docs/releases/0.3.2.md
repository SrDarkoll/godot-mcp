# Godot MCP v0.3.2 — Stable Production Release

Godot MCP is officially **Stable and Production-Ready** for **Godot Engine 4.x**!

Connect modern AI assistants (**Cursor**, **Claude Desktop**, **Antigravity**, **Roo Code**, **Cline**, and custom agents) directly to your running Godot editor and game runtime.

---

### Quickstart (Zero-Friction Bootstrap)

```bash
npx @srdarkx/godot-mcp init path/to/your/godot-project
```

#### Auto-Configure for AI Clients

```bash
# Cursor (.cursor/mcp.json)
npx @srdarkx/godot-mcp init . --client cursor

# Claude Desktop (claude_desktop_config.json)
npx @srdarkx/godot-mcp init . --client claude

# Google Antigravity / Gemini
npx @srdarkx/godot-mcp init . --client antigravity
```

---

### Key Features & Architecture

- **Stable Status**: Full production status for Godot Engine 4.x.
- **183 Canonical Tools across 8 Profiles**: `minimal`, `core`, `2d`, `3d`, `navigation`, `ui`, `runtime`, `full`.
- **Enterprise Safety Architecture**: Kernel-level project leasing (Windows Named Pipes), addon journal & rollback barrier, defensive recursion budgets, reflection safety sandbox, and atomic multi-file write transactions.
- **Interactive DAP Debugger**: Live breakpoints, stepping, stack frames, and lazy variable inspection.
- **Headless Process Manager**: Autonomous compilation, testing, and execution without GUI dependencies.
- **Multimodal Visual Grounding**: 2D/3D editor viewports and running game frame captures as PNGs.
