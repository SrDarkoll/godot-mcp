# Godot MCP 0.2.0 Release Candidate

Godot MCP 0.2.0 packages the hardened Phase 9 codebase into a zero-friction, single-package distribution while preserving the existing safety and validation model.

## Highlights

- **One public package:** users install or invoke `@srdarkx/godot-mcp`; `@godot-mcp/protocol`, `@godot-mcp/server`, and `@godot-mcp/godot-addon` remain bundled private implementation details.
- **Zero-friction bootstrap:** `init` can discover Godot, install and enable the addon, persist a tool profile, and safely merge MCP client configuration.
- **183 tools / 8 profiles:** `minimal`, `core`, `2d`, `3d`, `navigation`, `ui`, `runtime`, and `full`.
- **Advanced debugging:** live DAP breakpoint control, stepping, call stacks, scope variables, and compatibility handling for Godot 4.6.3.
- **Headless automation:** managed Godot CLI processes for import, validation, tests, and background execution.
- **Release hardening:** exact internal bundle validation, external runtime dependency promotion, clean-consumer install smoke tests, npm 11 dry-run JSON compatibility, and coordinated release-version checks.

## Intended npm flow

After explicit publication authorization:

```powershell
npx -y @srdarkx/godot-mcp init . --client antigravity
```

The package requires Node.js 22+ and is Tier-1 validated on Windows with Godot 4.6.3-stable.

## Release gate

Before real publication, all of the following must be freshly green on the release commit:

```powershell
npm install --ignore-scripts --no-audit --no-fund
npm run check:public-package
npm run test:release-scripts
npm run build
npm run typecheck
npm test
npm run release:pack
npm run test:distribution
npm run test:distribution
npm run release:dry-run
$env:GODOT_BIN="C:\path\to\Godot_v4.6.3-stable_win64.exe"
powershell -ExecutionPolicy Bypass -File .\scripts\run-all-gates.ps1
```

## Publication boundary

This release-preparation change does not run `npm publish`, create a Git tag, or create a GitHub Release. Those actions require separate explicit authorization after the release commit passes the complete gate above.
