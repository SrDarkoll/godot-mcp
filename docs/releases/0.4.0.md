# Godot MCP v0.4.0 — Audited Automation Enhancements

Version 0.4.0 adds nine verified MCP tools to the existing stable Godot 4.x release. The public catalog now contains 192 tools across eight bounded profiles.

## New automation capabilities

- `scene.batch.preview` and `scene.batch` prevalidate up to 64 native scene/resource operations and apply them as one Undo/Redo action with stale-state protection.
- `project.events` provides resumable, bounded event pages for editor connection, scene, filesystem, import and runtime state changes.
- `resource.dependencies`, `resource.impact` and `editor.import_resources` expose dependency graphs, inbound-reference preflight and confirmed editor reimport.
- `visual.compare` produces a deterministic pixel difference report and retained PNG from two verified session screenshots.
- `performance.snapshot` and `performance.compare` retain runtime samples and evaluate relative regression budgets supplied by the caller.

## Safety and compatibility

All nine tools pass through the existing profile registry, permission policy, audit log, risk approval and recovery barriers. Batch edits are bounded and fingerprinted; project event queues report gaps and dropped source events; dependency scans skip links and report truncation; PNG decoding and performance sampling enforce strict limits.

The release targets Node.js 22 or newer and Godot Engine 4.x. The canonical Windows validation uses Godot 4.6.3.

## Validation evidence

- Node 22.13.0: 357 unit tests; typecheck; 18 general, 10 runtime and 2 visual integrations; headless process manager; advanced DAP debugger.
- Godot 4.6.3: 38 addon scripts plus the generated runtime logger.
- Node 24.20.0: 357 unit tests, typecheck and an external-consumer distribution smoke test.
- Package publication: metadata validation, 16 release-script tests, tarball installation outside the checkout and `npm publish --dry-run`.
