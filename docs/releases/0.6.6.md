# Godot MCP 0.6.6

Security maintenance release. Updates bundled runtime dependencies with upstream fixes and adds defense-in-depth checks to the Godot bridge.

- The public package bundles `@modelcontextprotocol/core` and `@modelcontextprotocol/server` 2.4.0 and `zod` 4.6.7. Because these dependencies are bundled, earlier tarballs carried the vulnerable 2.0.0 SDK and older Zod regardless of version ranges. `npm audit` now reports no known vulnerabilities.
- The addon's `script.create` handler rejects paths that are not ordinary `res://` project files (absolute, `user://`, `..`, backslash, drive-letter and `res://addons/godot_mcp/` paths). The MCP server already enforced this policy before sending the request; the addon now enforces it independently.
- Editor hello and management requests compare the session token with a length-checked constant-time comparison, consistent with the MCP pipe handshake.
- No tool behavior changes. Protocol remains 1 and the catalog remains 194 tools.

## Update

```powershell
npm install -g @srdarkx/godot-mcp@0.6.6
```

Preview and upgrade each intended project separately:

```powershell
npx --yes @srdarkx/godot-mcp@0.6.6 upgrade . --dry-run
npx --yes @srdarkx/godot-mcp@0.6.6 upgrade .
```

Review session restart and launcher changes before confirming. Backups and per-project configuration are retained. Reload an already-open Godot addon and reconnect the MCP client after upgrading that project; updating the global package alone does not change pinned launchers or loaded addon code.

Node.js 22 or newer is required. Native verification targets Windows and Godot 4.6.3.
