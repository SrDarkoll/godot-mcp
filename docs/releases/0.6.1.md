# Godot MCP v0.6.1

Version 0.6.1 makes upgrading an existing installation a single guided workflow, including recognized project-local Codex configurations from older releases.

```powershell
npx --yes @srdarkx/godot-mcp@latest upgrade .
```

The updater checks the installation before changing it. It asks before stopping the authenticated project session, creates backups, migrates recognized Codex launchers, installs the addon and runs doctor. Failed verification restores the earlier files; interrupted upgrades retain a recovery marker and can be retried. Other MCP entries and custom options are preserved.

Generated client launchers pin the installed version. `init` offers this upgrade workflow when it detects an existing Codex installation. In non-interactive mode it supplies the upgrade command; use `--yes` after `upgrade` to explicitly authorize stopping the project session.

The default migration scope is project-local Codex on Windows. Unrelated commands, other project targets, ambiguous layouts and conflicting external edits remain protected. Reload/rescan an open Godot project and reconnect the client after success.

Validation includes 401 unit tests, Godot compilation, rollback/live-session integration, an external-consumer package test and a genuine 0.5.3-to-0.6.1 migration that restarted the new server. See the [upgrade guide](../upgrading.md) and [verification report](../testing/2026-10-08-upgrade-verification.md).
