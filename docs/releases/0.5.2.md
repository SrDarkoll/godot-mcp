# Godot MCP v0.5.2

This patch clarifies the public package description: Godot MCP connects AI assistants such as Codex, Claude, and Cursor to Godot 4 so they can create and edit scenes, run games, debug code, and capture screenshots.

The package README and Codex setup guide now describe the Codex integration as available in npm version 0.5.1 and newer. Package and addon version identifiers are coordinated at 0.5.2.

## Install

```powershell
npx --yes @srdarkx/godot-mcp@0.5.2 init "C:\path\to\your\godot-project" --client codex
```

The existing 194-tool catalog and Windows/Godot 4.6.3 compatibility target apply to this patch. See [the 0.5.0 release notes](0.5.0.md) for geometry and capture behavior and [the Codex setup guide](../tools/codex.md) for configuration details.
