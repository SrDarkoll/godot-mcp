# Godot MCP v0.6.0

Version 0.6.0 improves the edit, run and inspect cycle: useful compiler errors, complete paginated TileMap reads, confirmed bulk-write counts, safer property assignment and diagnostics from failed game launches.

## Changes

- `script.validate` retains native error messages, source paths, numeric error codes and actual line numbers. Unknown columns and locations are null.
- `tilemap.get_cells` returns byte-bounded pages with `total_count`, `has_more`, `next_cursor` and a snapshot fingerprint. A changed map invalidates its cursor.
- Bulk writes have a bounded input buffer, explicit request IDs and verified applied counts. Transport failures keep their outcome unknown; the server does not replay mutations automatically.
- `node.set_property` validates native metadata, resource subclasses and safe conversions before creating Undo history. Invalid values and failed resource loads leave the prior value intact. Results identify unsaved changes.
- Failed launches retain native compilation diagnostics and a session-owned boot log. Debug queries, workflow snapshots and diffs can inspect that history without a connected runtime agent.
- `workflow.run_check` separates runtime health, engine diagnostics, declared project tests and visual review. Optional property/report contracts support pass, fail, pending and unavailable outcomes. Console text containing `FAIL` is not an automatic test contract.

## Upgrade

```powershell
npx --yes @srdarkx/godot-mcp@0.6.0 init "C:\path\to\your\godot-project" --client codex
```

This updates the bundled addon and server together. If Godot is already open, scan the project filesystem or reopen the project so the editor loads the updated addon.

For complete TileMap enumeration, keep requesting pages with `cursor: next_cursor` until `has_more` is false. Use `tilemap.inspect.used_cell_count` when only the count is needed. Handler cell limits are upper bounds; conservative input budgets can still reject a batch before it reaches the handler.

The catalog remains at 194 tools. The native behavior was verified on Windows with Godot 4.6.3. Geometric validation covers declared geometry, and pixel comparisons locate image changes; neither certifies resemblance to a reference image.

## Validation

The [feedback audit](../testing/2026-10-07-feedback-audit.md) records 388 passing unit tests, compiler checks and isolated Godot integration evidence. Controlled MCP writes of 128, 512, 1,285 and 1,907 cells were acknowledged and read back without losing the connection. Restoring the old input buffer reproduced close code 1009 at 1,285 cells; this does not establish the cause of the historical incident.

Release preparation additionally verifies synchronized versions, the public tarball, external-consumer installation, CLI/Codex setup and MCP startup before publication.
