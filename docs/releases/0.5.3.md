# Godot MCP v0.5.3

The npm README now opens with a prominent link to the [GitHub repository](https://github.com/SrDarkoll/godot-mcp), where users can find the source code, setup guides and issue tracker. It also invites users who find the package useful to star the repository.

The public package now includes `repository`, `homepage` and `bugs` metadata pointing to GitHub. Package, server and addon version identifiers are coordinated at 0.5.3.

## Install

```powershell
npx --yes @srdarkx/godot-mcp@0.5.3 init "C:\path\to\your\godot-project" --client codex
```

The existing 194-tool catalog and Windows/Godot 4.6.3 compatibility target apply to this patch.
