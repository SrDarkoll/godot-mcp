# Godot MCP v0.3.0 — Architectural Hardening & Durability Engine

Godot MCP v0.3.0 brings enterprise-level durability, kernel-level safety, and deep observability to the Godot 4.x Model Context Protocol integration.

---

### Key Highlights

- **Project Lease (`project-lease.ts`)**: Kernel-level multi-process mutual exclusion via Windows Named Pipes (`\\.\pipe\godot-mcp-project-<hash>`). Prevents conflicting concurrent operations across multiple AI clients or CLI instances, with instantaneous OS kernel cleanup on abnormal process termination.
- **Addon Journal (`addon-journal.ts`)**: Atomic plugin updates staged in `.godot-mcp/addon-backups/` with SHA-256 verification and atomic markers. Interrupted updates are automatically detected and restored on startup (`recoverPending`).
- **Serialization & Recursion Budgets (`argument-budget.ts`, `serialization_budget.gd`)**: Deep defensive bounds (64 depth, 50,000 items, 8 MB strings, cyclic structure detection via `WeakSet` and GDScript ancestor trees) preventing engine freezes and OOM crashes.
- **Reflection Safety Sandbox (`reflection-safety.ts`, `safety_policy.gd`)**: 31 dangerous reflective methods blocked, strict identifier validation, and node mutations strictly restricted to the edited scene tree (`_owned_target`).
- **Modular Recovery & Unified Diff Engine (`recovery-journal.ts`, `transaction-diff.ts`)**: Formal state machine transitions with crash journals, preflight editor validation, and unified context diffs with CRLF/LF detection and credential redaction.
- **Config Repair (`project-config.ts`, CLI `--repair`)**: Automated repair of damaged `.godot-mcp/config.json` with backups in `.godot-mcp/config-backups/`.
- **Observability & Telemetry (`telemetry.ts`, `session-storage.ts`, `session-export.ts`)**: Real-time p50/p95 latency percentiles, queue wait times, quota scanner, and SHA-256 indexed session exports.

All 183 canonical MCP tool contracts preserved.
